# Android 0.28.26 — griglia azioni tappa 2×2

## Criteri di accettazione

- **Dove sono** non compare nella gestione delle tappe.
- La modalità percorso dispone `Preferiti`, `Cerca`, `Mappa` e `Sosta CNG` in una griglia 2×2.
- Tutti i pulsanti mantengono altezza 56 dp ed etichetta su una riga.
- Il live gate produce `dist/compass-0.28.26-debug.apk`.

## Live gate

Installare l'APK, aprire **Organizza le tappe** e verificare la griglia sul dispositivo.
