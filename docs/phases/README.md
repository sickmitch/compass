# Historical iteration records

These documents preserve scenario checklists and acceptance evidence for individual
iterations. Versions, commands and local test counts describe those iterations, not the
current release. Some optional scenario runners build/install an APK; they are diagnostic
tools and are not the automatic-update workflow.

Start with the [condensed history](../history.md) or [current guides](../../README.md).
The [0.28.46 gate](android-0.28.46-nominal-routing-gate.md) retains the current pending
operator checklist. Use [client updates](../client-updates.md) for distribution;
standalone installation scripts have been removed.
